# Hi, I'm Francis 👋

I'm an independent software creator. I build complete products end to end — and,
more deliberately, the shared foundation they stand on.

Most of my work is one person carrying an idea all the way down the stack: a
reusable infrastructure layer (auth, config, observability, storage, a service
skeleton you clone to start a new product) that every product then builds on.
Backend, web, and native iOS — one coherent system rather than scattered apps.

### How I work

- **Foundation first.** I'd rather build auth / observability / deploy once,
  well, and reuse it — so each new product is days of business logic, not months
  of plumbing.
- **Inside-out.** Model → logic → make it work → then make it good. UI polish
  comes after the product loop actually runs, not before.
- **Ship to learn.** Real friction from shipping is the only thing worth
  designing around — structure follows practice, never the other way round.
